🦠 COVID-19 Data Analysis Using SQL
📌 About This Project

In this project, I explored global COVID-19 data using SQL Server.

The goal was to practice data analysis skills by answering real-world questions such as:

1. How deadly was COVID-19?

2. Which countries had the highest infection rates?

3. Which continents recorded the most deaths?

4. How did vaccination progress over time?

5. What percentage of each country’s population was vaccinated?

This project focuses on writing SQL queries to extract insights from raw data.

🛠 Tools Used

1. SQL Server

2. T-SQL (SQL language for Microsoft SQL Server)

3. Window Functions

4. CTEs (Common Table Expressions)

5. Temporary Tables

6. Views

🧠 What I Learned

Through this project, I improved my understanding of:

1. Writing clean SQL queries

2. Using GROUP BY and aggregate functions

3. Working with window functions

4. Creating rolling totals

5. Handling data type conversion (CAST, CONVERT)

6. Fixing arithmetic overflow errors

7. Using CTEs and temp tables to simplify complex queries

2. Analyze real-world datasets
