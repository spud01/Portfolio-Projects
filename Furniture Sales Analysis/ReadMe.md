# Furniture Sales Analysis Dashboard

## Overview
This project analyses furniture sales data spanning **2014-2017** across multiple regions in the United States. The analysis includes sales performance, profitability trends, regional comparisons, and customer segment insights using Microsoft Excel.

## Dataset Summary
- **Total Records:** 2,121 sales transactions
- **Time Period:** January 2014 - December 2017
- **Geographic Coverage:** 371 cities across 4 regions (South, West, East, Central)
- **Product Range:** 380 unique furniture products
- **Customer Segments:** Consumer, Corporate, Home Office

## Key Metrics
- **Total Sales:** $741,999.80
- **Total Profit:** $18,451.27
- **Total Quantity Sold:** 8,028 units
- **Average Order Value:** $349.83

## Project Structure
The workbook contains three main sheets:

### 1. Furniture_Sales
Raw dataset containing:
- Order details (Order ID, dates, shipping information)
- Customer information (Customer ID, name, segment, location)
- Product details (Product ID, category, sub-category, product name)
- Financial metrics (Sales, quantity, discount, profit)
- Calculated fields (Duration, Month)

### 2. Calculations
Supporting calculations and data transformations used for analysis

### 3. Dashboard
Interactive visual dashboard featuring:
- Sales trends over time
- Regional performance comparison
- Customer segment analysis
- Product category breakdown
- Key performance indicators (KPIs)

## Analysis Features
- **Time-based analysis:** Monthly and yearly sales trends
- **Geographic analysis:** Performance by region, state, and city
- **Customer segmentation:** Consumer vs. Corporate vs. Home Office
- **Product analysis:** Sales and profitability by sub-category
- **Shipping analysis:** Delivery duration impact on performance

## Tools & Techniques Used
- **Microsoft Excel** 
- **Pivot Tables** for data summarization
- **Data Visualisation** (Charts and graphs)
- **Slicers** for interactive filtering

## Key Insights
- Identified top-performing regions and customer segments
- Analysed profitability trends across product categories
- Evaluated shipping efficiency and its impact on customer satisfaction
- Tracked seasonal sales patterns for strategic planning

## How to Use
1. Download the `Furniture_Sales.xlsx` file
2. Open in Microsoft Excel (2016 or later recommended)
3. Navigate to the **Dashboard** sheet for visual insights
4. Use slicers to filter data by region, segment, or time period
5. Explore the **Furniture_Sales** sheet for detailed transaction data
